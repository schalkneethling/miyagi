Project Goal Summary

Miyagi aims to be a lightweight, web-platform-first component workbench for frontend teams and design-system maintainers. The goal emphasizes ordinary component folders, iframe isolation, project-owned render functions, reliable mocks and schema validation, static builds, HTML validation, performance reporting, design-token documentation, and automation-friendly CLI/API surfaces. Current focus areas are plugin boundaries for ecosystem-specific behavior and a flagship Web Components example.
