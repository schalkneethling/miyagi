## Benefits

<CardGrid>
  <Card title="Zero project overhead">miyagi only needs one configuration file.</Card>
  <Card title="Flexible structure">Works with any directory structure (one folder per component).</Card>
  <Card title="Encapsulated development">Develop components in isolation.</Card>
  <Card title="Backend-independent">Static or dynamic mock data — no backend needed.</Card>
  <Card title="Schema validation">Validates mock data against your JSON schema files.</Card>
  <Card title="Component documentation">Document components using markdown.</Card>
  <Card title="Customizable layout">Customize the layout to fit your project's design.</Card>
  <Card title="Any template engine">Use any engine by providing your own render function.</Card>
  <Card title="Static builds">Create a static build of your component library.</Card>
  <Card title="CLI scaffolding">Create components and mock data via CLI.</Card>
  <Card title="Design token overview">Auto-generated overview based on CSS custom properties.</Card>
</CardGrid>
